## 源码隔离边界

正式命令只从当前活动代码目录导入 baseline 代码：

| 模型 | 网络源码 |
|---|---|
| MetaFi++ | `model\metafi\ChannelTrans.py`、`model\metafi\mynetwork.py` |
| HPE-Li | `model\hpeli\SK_network.py`、`model\hpeli\hpeli.py` |
| DT-Pose | `model\model.py`、`model\utils\graph.py`、`model\utils\tgcn.py` |

三者有意共享同一份 `train_pose.py`、`feeder\mmfi.py` 和 `utils.py`，用于统一数据划分、
样本范围、训练循环和指标口径。共享运行框架不等于共享模型网络；`experiment_name`
会分别实例化 `metafinet`、`hpelinet` 或 `ViT_Pose_Decoder`。

`model_source_hashes.json` 锁定 8 个模型源码文件。启动器每次运行前都会检查文件清单
和 SHA-256，任何多文件、少文件或内容变化都会在 GPU 训练前退出。

## 历史 batch 口径

MetaFi++、HPE-Li、DT-Pose 的姿态默认配置分别为 `16/16/1.85e-3`、
`16/16/1e-3`、`32/16/8.49e-4`（配置 batch / micro-batch / 学习率）。历史
`train_pose.py` 的 `step_count` 没有递增，因此 DT-Pose 姿态阶段实际每 16 个样本
更新一次。该行为已记录但未修改；不能把它描述为标准梯度累积后的有效 batch 32。
