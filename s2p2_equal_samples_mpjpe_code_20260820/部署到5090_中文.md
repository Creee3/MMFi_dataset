# 等样本三模型代码包部署说明

更新时间：2026-08-21

## 1. 这个压缩包是什么

这是 2026-08-20 整理的三模型等样本实验代码包，包含：

- MetaFi++、HPE-Li、DT-Pose 的网络源码；
- MM-Fi 数据读取、划分和样本范围适配；
- 姿态训练入口和 DT-Pose CSI 自监督预训练入口；
- 完整 3×3 调度器、汇总脚本、配置模板和中文说明；
- 模型源码 SHA-256 清单。

包内特意不包含历史 `pretrain_weights/`、旧传输压缩包、训练结果、缓存和
`.ipynb_checkpoints`。DT-Pose 的等样本预训练权重需要在 5090 上重新生成，
不能把历史权重直接当作新权重使用。

## 4. 运行顺序

如果要做严格等样本的完整 3×3，顺序必须是：

1. 先运行 `run_dtpose_equal_samples_pretrain.py`，生成 9 个格子的预训练权重；
2. 再把该输出目录作为 `--dtpose_pretrain_root` 传给 3×3 姿态 runner；
3. MetaFi++ 和 HPE-Li 不依赖 DT-Pose 预训练，可以单独运行。

日常命令以项目根目录 `launchers\README_中文.md` 为准；底层 runner 的完整参数
见本目录 `完整3x3三个模型使用说明_中文.md`。

输出目录请使用新的目录名；中断后使用原输出目录加 `--resume`，不要删除历史
结果，也不要把新参数混入已经生成的 `manifest.json`。

## 5. 代码保护

3×3 runner 在训练前会检查 `model_source_hashes.json`。模型源码文件数量或
SHA-256 不一致时会在 GPU 训练前停止。这个包不修改 5090 上已有的根目录主线、
旧 bundle、数据集和历史结果。
